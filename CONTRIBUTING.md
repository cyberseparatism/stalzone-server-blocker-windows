# Contribution Guide

Спасибо за интерес к проекту.

## Баги

Перед созданием Issue проверьте, не описана ли проблема ранее. Для UI-багов приложите скриншот и укажите масштаб интерфейса Windows (100%, 125%, 150% и т. д.).

## Pull Requests

1. Создайте fork репозитория.
2. Создайте отдельную ветку для изменения.
3. Не смешивайте рефакторинг и новую функцию в одном PR без необходимости.
4. Проверьте запуск на Windows PowerShell 5.1.
5. Если менялся UI — приложите скриншот.
6. Не добавляйте отключение проверки TLS, неизвестные бинарники или сбор пользовательских данных.

## Стиль

- пользовательский интерфейс — преимущественно на русском;
- технические названия (`IP`, `PowerShell`, `Windows Firewall`) допустимы;
- ошибки должны объяснять пользователю, что произошло и что можно сделать;
- правила брандмауэра должны оставаться изолированными в группе `STALZONE Server Blocker`.
