# Security Policy

## Поддерживаемые версии

На данный момент исправления безопасности выпускаются для последней опубликованной версии.

## Сообщить об уязвимости

Если вы обнаружили проблему, которая может привести к небезопасному изменению правил брандмауэра, выполнению нежелательных команд или обработке недоверенных данных, пожалуйста, не публикуйте рабочий exploit в открытом Issue.

Контакты:

- Discord: `cyberseparatism`
- Telegram: `@cyberseparatism`

В сообщении желательно указать:

- версию приложения;
- версию Windows;
- шаги воспроизведения;
- ожидаемое и фактическое поведение;
- минимальный proof-of-concept без чувствительных данных.

## Модель безопасности

Программа:

- не отключает TLS validation;
- не принимает пароли или игровые токены;
- использует elevation только для изменения Windows Firewall;
- удаляет только правила своей группы `STALZONE Server Blocker`;
- не внедряется в игровой процесс.
